ProtHMSO uses masked protein language models for multi-site protein sequence optimization

Biology+AI Daily summarizes ProtHMSO, a heuristic protein sequence design framework that uses masked protein language models—mainly ESM-2—to propose context-aware single- and multi-site substitutions. The method can act as a standalone optimizer or as a mutation operator for genetic algorithms and MCTS, with tests on antimicrobial peptide design and ProteinGym/clinical variant benchmarks.

AlloGen designs conformation-selective binders with differential state scoring

AlloGen targets binder design for allosteric systems by ranking or guiding generated binders with a learned differential selectivity score between desired and undesired receptor conformations. The scorer is an SE(3)-invariant interface graph transformer trained with DockQ grounding and paired InfoNCE fine-tuning, with reported out-of-distribution target performance and experimental validation on calmodulin.

Information Bonus metric asks when AlphaFold2 representations add value over protein language models

A paper introduces Information Bonus, a task-level metric comparing frozen AlphaFold2 Evoformer representations with frozen ESM-2 embeddings under protein-level cross-validation. The thread highlights allostery as a positive-IB regime, binding affinity as negative-IB under the benchmark design, and warns about residue-level split artifacts that can inflate performance and reverse representation rankings.

DegradoMap predicts PROTAC-mediated protein degradability from structure and E3 identity

DegradoMap is a structure-aware graph neural network for early PROTAC target selection. It uses AlphaFold protein structures, E3 ligase identity, lysine-weighted pooling, cross-attention, and DepMap context features to predict degradability, while reporting target-unseen evaluation, E3-transfer behavior, recommendation metrics, calibration, and limitations from data imbalance.

MOLE-RAG augments LLM molecular property prediction with chemistry retrieval and structural neighbors

MOLE-RAG is a training-free framework for molecular property prediction that enriches LLM prompts with literature snippets, descriptors, functional groups, names, and structurally similar labeled examples. Across MoleculeNet tasks with scaffold splits, the strongest gains come from task-adaptive structural retrieval, with text retrieval and descriptor injection adding further context.

AMREC treats invalid SMILES as recoverable molecular states for agentic molecule repair

AMREC reframes invalid LLM-generated SMILES as corrupted molecular states and tries to recover chemically valid molecules while preserving target scaffolds and description-derived requirements. The system uses explicit requirement checking, mismatch tracking, planning, candidate exploration, persistent candidate pools, and trajectory-level selection.

SECS combines contrastive learning and evolutionary search for raw-spectra molecular structure elucidation

SECS is an end-to-end computer-assisted structure elucidation system that maps raw multimodal spectra and molecules into a shared contrastive embedding space, then retrieves and refines candidate structures with a graph genetic algorithm. It supports NMR, IR, MS/HSQC subsets, reports calibrated confidence, detects misassigned structures, and is positioned for lab automation workflows.

AF Cache accelerates high-throughput AlphaFold PPI screening with cached MSAs and bucketing

AF Cache is a Nextflow pipeline for large-scale AlphaFold2/3 protein–protein interaction screens. It caches monomer MSAs and, for AlphaFold2, buckets sequences by length to reduce repeated JAX compilation. A 100-protein all-against-all mitochondrial benchmark reports large MSA-stage speedups and a more than 50% reduction in AF2 prediction plus compilation GPU time.
