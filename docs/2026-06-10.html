AI Research & Systems

Tilde introduces Parallax local-linear correction for softmax attention

Tilde describes Parallax, an attention modification that preserves the local-linear regression view of attention while avoiding a per-token solve. The additive covariance correction is designed to fit into FlashAttention with one extra branch, aiming for better arithmetic intensity and Hopper decode performance.

The reported results show gains over vanilla attention and sequence-mixer baselines at 0.6B and 1.7B scales, including pretraining and NanoGPT speedrun settings.

MLX support arrives for Cohere North Mini Code 1.0

Prince Canuma reports day-zero MLX support for CohereLabs/North-Mini-Code-1.0, described as a 30B-parameter mixture-of-experts coding model with 3B active parameters.

The post reports roughly 66 tokens per second in BF16 before compression and includes example mlx-vlm install and server commands for local agent use.

Bio-AI & Protein Modeling

AlphaFold 3 source code released under Apache 2.0

Sergey Ovchinnikov notes that the AlphaFold 3 source code is now open source under Apache 2.0, though model weights remain unavailable.

Follow-up discussion turns to whether OpenFold3 weights could be ported into the AF3 JAX code. Mohammed AlQuraishi says current OF3p2 models are not bitwise compatible out of the box, but future OpenFold3 versions may be, and the current OpenFold3 speed gap should be addressable with optimization.

ESM-C antibody representations may miss CDRH3 ordering signals

Diego del Alamo highlights a possible antibody language-model limitation: mean-pooled ESM-C CDRH3 representations reportedly cannot distinguish real antibodies from antibodies with scrambled CDRs.

VHHBERT appears to distinguish the cases only for natural sequences. A follow-up argues that many models may represent CDRH3 residues largely as linear combinations of residue identity and position features, which could be too weak for antibody modeling.
