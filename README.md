# News

[Read News](https://lachlanstuart.github.io/newspaper-issues/)

Daily research, reading, and language practice, generated on claw2.

`docs/` contains the issue archive, date aliases, and latest issue. GitHub Pages serves this folder from `main`. Raw source data, intermediate reports, credentials, and host logs are not published in this repository.

Pipeline code, source configuration, editorial instructions, and operating documentation live in [small-projects/projects/daily-newspaper](https://github.com/LachlanStuart/small-projects/tree/main/projects/daily-newspaper).
